Like most first attempts, it eventually disbanded, but its legacy lives on in projects like [Spring Lock](/docs/spring-lock).

## What Was HSAG Ingeniousity?

HSAG Ingeniousity was the last company in my series of defunct ventures. It followed the same architecture as **AGNBOC** (my first company) and was run with a small team of around two people. The focus was on:

- **iOS Shortcut Development** — creating utility and security shortcuts for the Apple ecosystem.
- **HSAG Software Services** — a sub-brand offering technical solutions.
- **YouTube Content** — the **Techneeka** YouTube channel.

Its most significant product was **HSAG AppLock**, which later evolved into **Spring Lock** (the current flagship shortcut).

---

## Products & Projects

### Spring Lock (formerly HSAG AppLock)

The flagship product. Originally released under the HSAG brand as **HSAG AppLock**, it was later rebranded to **Spring Lock** in Version 5.2. The shortcut provides app-locking functionality using system automations and CryptoKit-based encryption.

See the [Spring Lock](/docs/spring-lock) documentation for full details.

### HSAG UI

A custom UI framework designed for Apple Shortcuts that prioritises aesthetic consistency. It evolved through several versions:

- **HSAG UI 3** — introduced in Spring Lock v5.0
- **HSAG UI 4** — current iteration, used in Spring Lock v5.3+

### HSAG Ultimate Updater

An in-shortcut update mechanism that replaced the earlier **Swing Updater**. It checks for new versions and applies updates seamlessly. Used by Spring Lock.
