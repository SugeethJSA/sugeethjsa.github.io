This page is a documentation page for Spring PDF Tools, a shortcut that I created a while ago when I wanted to work with PDFs.

A lot of shortcuts claim to solve a single PDF problem, but overtime they get lost in our shortcuts library. Some of them are custom built, while others are somewhat generic. Either way, I prefer such tools as they’re mostly offline tools with on-device processing.

This shortcut combines some useful tools that I thought would help everyone out!

Module: RoutineHub
RH ID: 21134

Limitations of this shortcut: As with all Apple shortcuts, this shortcut loads all objects and manipulations into memory. So if you do use this shortcut, please keep in mind that currently it can not handle more than a 100 images/objects or more than a 400 MB PDF.
